# Agente Integrado de Qualificação e Diagnóstico

## Descrição

Descubra o que seu negócio realmente precisa para crescer no digital. Este assistente faz algumas perguntas rápidas para entender seus objetivos e, em poucos minutos, entrega um diagnóstico personalizado — o primeiro passo para um site estratégico e eficiente.

## Quebra-gelos

- Descobrir o que preciso
- Quero um site
- Melhorar meu site atual
- Entender como funciona
